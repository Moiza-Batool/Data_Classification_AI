# Data Classification Using AI
A simple **AI-powered data classification project** built in **Python 3.12** using the **Iris dataset** and the **K-Nearest Neighbors (KNN)** machine learning algorithm. The project demonstrates the complete machine learning workflow including data preprocessing, feature scaling, model training, prediction, and performance evaluation.

## Features
1. Uses the built-in Iris dataset from Scikit-learn
2. Feature standardization using StandardScaler
3. Data splitting into training and testing sets
4. Classification using the K-Nearest Neighbors (KNN) algorithm
5. Model evaluation using Accuracy Score
6. Confusion Matrix generation
7. Classification Report with Precision, Recall, and F1-Score
8. Clean console-based output showing each stage of the process

## Technical Stack:
* Python 3.12
* Scikit-learn
* VS Code
* Numpy

## How to Run

1. Clone the repository.
git clone <repository-url>

2. Navigate to the project folder.
cd Data_Classification_AI

3. Install the required dependencies.
pip install scikit-learn

4. Run the program.
python data_classification.py
